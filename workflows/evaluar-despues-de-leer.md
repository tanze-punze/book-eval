# Evaluar un Libro Despues de Leer

Workflow para evaluacion completa post-lectura. Produce una evaluacion rigurosa con
puntuacion numerica, verificacion de claims, y veredicto final. Usar la plantilla
rellenable en `templates/rubrica-puntuacion.md` para la puntuacion formal.

---

## Paso 1: Evaluacion con Rubrica Completa

Abrir `templates/rubrica-puntuacion.md` y puntuar cada una de las 9 dimensiones con
justificacion. Las 9 dimensiones son:

1. **Autoridad** (x3) -- Credenciales del autor
2. **Precision** (x3) -- Calidad de citas y fuentes
3. **Profundidad** (x3) -- Mas alla de lo superficial
4. **Utilidad Practica** (x3) -- Accionable y aplicable
5. **Estructura** (x2) -- Organizacion logica
6. **Balance** (x2) -- Multiples perspectivas
7. **Vigencia** (x2) -- Actualidad de la informacion
8. **Escritura** (x2) -- Claridad y calidad de prosa
9. **Respaldo Editorial** (x1) -- Proceso editorial

Si ya completaste el workflow de "evaluar mientras lees", usar las notas por capitulo
como insumo para la rubrica.

---

## Paso 2: Analisis de la Bibliografia

La bibliografia es el ADN de un libro de no ficcion. Su analisis revela mucho sobre
la seriedad de la investigacion del autor.

### 2.1 Cantidad
| Cantidad de fuentes | Evaluacion |
|---|---|
| 0 | Inaceptable para no ficcion informativa |
| 1-10 | Muy pobre |
| 11-30 | Minimo aceptable |
| 31-100 | Bueno |
| 100+ | Indica investigacion seria (verificar calidad) |

### 2.2 Calidad de las fuentes

Clasificar las fuentes en:

| Tipo | Confiabilidad | Ejemplos |
|---|---|---|
| Fuentes primarias academicas | Muy alta | Papers peer-reviewed, datos oficiales, documentos originales |
| Libros academicos/universitarios | Alta | Publicados por editoriales academicas con proceso de revision |
| Informes de organizaciones | Alta | OMS, Banco Mundial, institutos de investigacion |
| Libros de divulgacion citados | Media | Otros libros de no ficcion (depende de su propia calidad) |
| Articulos periodisticos | Media-baja | Prensa generalista, revistas no academicas |
| Paginas web / blogs | Baja | Contenido online sin revision editorial |
| Comunicaciones personales | Baja | Entrevistas, correos, conversaciones |

Regla orientativa: al menos el 40-50% de las fuentes deberian ser de confiabilidad
"alta" o "muy alta" para un libro que pretende informar con rigor.

### 2.3 Diversidad
- Las fuentes representan multiples perspectivas o solo una?
- Hay fuentes que contradicen la tesis del autor? (senal positiva si las hay y las discute)
- Las fuentes cubren distintas disciplinas relevantes o son todas del mismo nicho?
- Hay autocitas excesivas? (el autor cita principalmente sus propios trabajos anteriores)

### 2.4 Vigencia
- Cual es la mediana de antiguedad de las fuentes?
- En campos de rapida evolucion, hay fuentes de los ultimos 5 anos?
- Las fuentes mas antiguas son clasicos justificados o datos obsoletos?

## Paso 3: Verificacion de Claims Clave

Seleccionar 5 claims centrales del libro y verificar cada uno contra fuentes independientes.

### 3.1 Como seleccionar los 5 claims

Elegir claims que sean:
1. **Centrales para la tesis:** Si este claim es falso, el argumento del libro se debilita
2. **Verificables:** Datos concretos, no opiniones vagas
3. **Sorprendentes:** Las afirmaciones contraintuitivas son las que mas necesitan verificacion
4. **De diferentes secciones:** Para evaluar la consistencia del rigor a lo largo del libro
5. **Con implicaciones practicas:** Si vas a actuar sobre un claim, mejor verificarlo

### 3.2 Proceso de verificacion por claim

Para cada claim:

1. **Transcribir el claim exacto** del libro (pagina y cita textual)
2. **Identificar la fuente citada** (si la hay)
3. **Buscar la fuente original** y leer el abstract/resumen
4. **Comparar:** El autor represento la fuente correctamente?
5. **Buscar fuentes independientes** que confirmen o contradigan
6. **Clasificar resultado:**

| Resultado | Significado |
|---|---|
| **Verificado** | El claim es correcto y esta bien respaldado |
| **Parcialmente correcto** | El nucleo es cierto pero con matices importantes que el autor omitio |
| **Distorsionado** | La fuente original dice algo diferente a lo que el autor presenta |
| **No verificable** | No se puede confirmar ni desmentir con las fuentes disponibles |
| **Falso** | El claim es incorrecto segun la evidencia disponible |

### 3.3 Interpretar resultados

| Claims verificados (de 5) | Evaluacion |
|---|---|
| 5/5 | Excelente -- autor riguroso y preciso |
| 4/5 | Bueno -- confiable con reservas menores |
| 3/5 | Regular -- verificar todo claim antes de aceptarlo |
| 2/5 | Pobre -- problemas serios de precision |
| 0-1/5 | Inaceptable -- no confiar en la informacion del libro |

## Paso 4: Test de Utilidad Practica

Despues de leer el libro completo, responder honestamente estas preguntas:

### 4.1 Test del parrafo
> "Puedo describir en 1 parrafo lo que aprendi de este libro que NO sabia antes?"

Si no puedes, el libro probablemente no aporto conocimiento nuevo significativo.

### 4.2 Test de la herramienta
> "Tengo al menos 1 herramienta, framework, concepto o metodologia nueva que
> puedo aplicar en mi vida o trabajo?"

Un buen libro de no ficcion practica deberia dejarte con algo aplicable.

### 4.3 Test del "y que?"
> "El conocimiento que obtuve tiene aplicacion real? Cambia alguna decision o
> comportamiento mio? O es solo informacion interesante sin consecuencias?"

La informacion que no cambia nada tiene valor de entretenimiento pero no de utilidad.

### 4.4 Test de la recomendacion
> "A quien le recomendaria este libro, y para que?"

Si no puedes responder esto, el libro probablemente no tiene una audiencia clara
o un proposito definido.

### 4.5 Test de la alternativa
> "Podria haber obtenido esta informacion de un articulo de 20 minutos en lugar
> de un libro de 300 paginas?"

Si la respuesta es si, el libro tiene un problema de densidad de informacion
(demasiado relleno).

## Paso 5: Comparacion con el Campo

Situar el libro en el contexto mas amplio de la literatura sobre el tema.

### 5.1 Consenso vs. Outlier
- Las conclusiones del autor estan en linea con el consenso del campo?
- Si contradice el consenso, presenta evidencia suficiente para justificarlo?
- Un libro que contradice el consenso sin evidencia solida es sospechoso
- Un libro que contradice el consenso CON evidencia solida puede ser valioso

### 5.2 Comparacion con alternativas
- Que otros libros abordan el mismo tema?
- Como se compara en terminos de rigor, profundidad y utilidad?
- Hay un libro que haga lo mismo mejor?

### 5.3 Contribucion al campo
- El libro aporta algo genuinamente nuevo (nueva investigacion, nueva sintesis,
  nueva perspectiva)?
- O es una recopilacion de lo ya conocido en un formato mas accesible?
- Ambos pueden ser valiosos, pero la contribucion original merece mas credito

## Que Hacer con la Evaluacion

### Si el libro es Excelente o Bueno
- Conservar la evaluacion como referencia para recomendaciones futuras
- Identificar las fuentes mas valiosas de la bibliografia para lectura adicional
- Aplicar las herramientas o frameworks aprendidos

### Si el libro es Regular
- Extraer los 2-3 insights mas valiosos y descartar el resto
- Buscar fuentes mas confiables sobre los mismos temas
- No citar este libro como fuente primaria sin verificacion

### Si el libro es Pobre o Evitar
- Documentar por que, para que otros se beneficien de tu evaluacion
- No perder mas tiempo intentando rescatar valor del libro
- Buscar activamente alternativas recomendadas por expertos del campo
