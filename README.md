
# book-eval

**A Claude Code skill for evaluating non-fiction books.**

This repository provides a comprehensive skill set and workflow for analyzing and evaluating non-fiction literature using AI. It synthesizes established evaluation frameworks to ensure rigorous, high-quality assessments of full texts.

## 🌟 Features

* **Synthesized Evaluation Rubrics:** Combines criteria from multiple authoritative and academic frameworks:
* **CRAAP Test** (Currency, Relevance, Authority, Accuracy, Purpose)
* **SIFT** (Stop, Investigate the source, Find better coverage, Trace claims)
* **Thwink** (Fact-checking and logical flaw analysis)
* **NCTE Orbis Pictus** (National Council of Teachers of English criteria for outstanding non-fiction)
* **SPI/ANECA** (Spanish academic evaluation system criteria)


* **Deep-Reading Workflows:** Includes specialized workflows capable of handling and processing full PDF and EPUB books for comprehensive, context-aware analysis.

## 📂 Repository Structure

* `📁 checklists/` - Evaluation checklists and criteria based on the synthesized rubrics.
* `📁 references/` - Reference materials and documentation for the various academic frameworks used.
* `📁 templates/` - Standardized output templates for generating book evaluation reports.
* `📁 workflows/` - Automated evaluation workflows (including the deep-reading pipeline for full PDFs/EPUBs).
* `📄 SKILL.md` - Core skill definitions and system instructions for Claude.

## 🚀 Getting Started

To use this skill, load the repository into your Claude Code environment. You can utilize the included workflows to process full PDFs or EPUBs, passing the text through the synthesized evaluation rubrics to generate structured, academic-grade reviews using the provided templates.
